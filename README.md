# Calculadora-Python
Calculadora em Python

Este projeto se trata de uma simples calculadora desenvolvida em Python e executada através do arquivo >calculadora.sh< permitindo rodar diretamente pelo terminal Linux.


⦁	Não é mandatório que você já tenha o Python3 (que utilizamos nesse projeto) previamente instalado, porém requeremos Git já em seu terminal. 
⦁	Ao executar o arquivo calculadora.sh ele fará uma verificação em sua maquina para checar se você possui Python3 em sua versão mais recente, se não, ele atualizará;
   caso não o tenha instalado, ele instalará automaticamente.


Passo 1: Insira o seguinte comando no seu terminal: git clone https://github.com/yasminkaroly/Calculadora-Python.git (copie e cole)
Passo 2: Após a instalação ser concluída insira o comando "cd Calculadora-Python" para você acessar a pasta
Passo 3: Ao acessar, verifique se tem a permissão para execução do arquivo calculadora.sh (utilize o comando "ll" para fazer essa verificação)
Passo 4: Caso não tenha, insira "chmod +x calculadora.sh" e estará liberado (em caso de erro, utilize sudo antes do código para executar o comando como administrador)
Passo 5: Tendo a permissão de execução, basta colocar "./calculadora.sh" em seu terminal e já poderá testar o código Python em seu terminal. :D
